# The 12 principles of animation, in Carvercat

One page per principle. Each page says what the principle is for, how to build it with Carvercat's native tools (presets, keys, easing, parenting, stagger), the numbers measured on verified templates, and the lint traps that go with it. Measured on Carvercat 0.1.6 (rev 1105), 2026-10-27, with `carvercat_inspect mode:curves` and checked with `carvercat_look`; every example below is a verified template you can place from the Library.

The short form of all twelve is in [../motion-principles.md](../motion-principles.md) §3; per-style frame counts are in [../timing-by-style.md](../timing-by-style.md).
