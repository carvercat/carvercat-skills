# Design units: the one way to talk to Carvercat

Every value an agent writes or reads is in **design units** (API 1.0, units `design/1`, scene document `carvercat/2.0`). The app converts inside; you never convert. Verified against a headless Carvercat built from Carvercat 0.1.8 (`ai/scripts/verify_examples.py`; each example below names its case as "verified: case-name").

| Thing | Unit |
|---|---|
| Space | **px from the frame's top-left, y down**. `x`, `y` are the top-left of the object's box; a child's are from its parent's top-left. `width`, `height` px or `%` of the frame |
| Rotation | `rotate` in degrees **clockwise** (`45`, `"45deg"`, `"0.125turn"`) |
| Scale, opacity | `scale` `1.2` or `"120%"`; `opacity` `0.5` or `"50%"` |
| Pivot | `transformOrigin` as in CSS (`"left top"`, `"50% 50%"`, `"20px 30px"`) |
| Colour | CSS as you see it: `"#FF7A00"`, `"rgb(255 122 0)"`, `"orange"`; gradients `"linear-gradient(90deg, #ff7a00 0%, #1b1b1b 100%)"`. Never a linear-light array |
| Time | frames (`36`), `"36f"`, `"1.5s"`, `"500ms"`. Keyframe `at` is **from the start of the object**; `atComp` is the comp's clock |
| Text | `fontSize` px (a true em), `fontFamily`, `fontWeight` (`400`, `700`, `"bold"`), `fontStyle`, `letterSpacing` px/em, `lineHeight` a multiple (`1.2`) or px, `textAlign`, `verticalAlign`, `whiteSpace` (`nowrap` point text, `normal` box text) |
| Shapes | `borderRadius` px or `%` of the short side (`"50%"` = stadium), `sides`, `points`, `innerRadius`, `strokeWidth` px, `strokeDasharray`, `strokeLinecap`, `strokeLinejoin`, `strokeAlign`, `trimStart`/`trimEnd`/`trimOffset` in `%`, `softEdge` px (one soft edge for fill and stroke; `strokeSoftEdge` is its old name) |
| Effects | `blur` px (a Gaussian sigma), `dropShadow "0 4px 8px #0008"` (y **down**), `glow "12px #ffcc00 0.6 0.2"`, `brightness`, `contrast`, `mixBlendMode`, `filter` (a CSS list), `mask`, `clipPath`, `feather` px |
| Easing | `linear`, `ease`, `ease-in`, `ease-out`, `ease-in-out`, `cubic-bezier(a,b,c,d)`, `steps(n, jump-end)`, `hold`, `spring(duration, bounce)`, `spring(stiffness, damping, mass)`, `spring-gentle\|wobbly\|stiff\|slow\|default`. A key's `ease` shapes the segment that **leaves** it (as CSS does) |

The full table with ranges, defaults and the Resolve / After Effects carve status is generated by the app: `carvercat://schema/design` (also kept as the app's design-units reference document). `carvercat://schema/commands` and `carvercat://schema/scene` are JSON Schema for every command and for the scene document. Read the live schema before using a key you have not used; a refusal names the valid forms and a corrected example.

## The loop

1. Read `carvercat://index`, `conventions`, `review`, `workflows`, `commands`, `schema/design`.
2. **Build the whole scene in one call** (`scene.apply`), dry run first.
3. Edit by selector (`property.set`, `anim.set`) or with a helper (`layout.*`, `text.fit`, `motion.apply`).
4. Check without rendering (`measure.*`, `carvercat_inspect mode:lint|timing|expect`), then one `carvercat_look`.
5. **`carve.preflight` before any send** to Resolve or After Effects.

## A whole scene in one call (verified: lower-third-scene)

```json
{"command": "scene.apply", "args": {"mode": "merge", "dry_run": true, "scene": {
  "schema": "carvercat/2.0",
  "comp": {"width": 1920, "height": 1080, "fps": 30, "duration": "4s"},
  "children": [
    {"id": "plate", "type": "rect", "tags": ["card"],
     "style": {"x": 160, "y": 760, "width": 900, "height": 200, "fill": "#1a1c26", "borderRadius": 24},
     "keyframes": [{"at": 0, "props": {"x": -900}, "ease": "cubic-bezier(.16,1,.3,1)"}, {"at": 18, "props": {"x": 160}}]},
    {"id": "name", "type": "text", "text": "Alex Morgan",
     "style": {"x": 210, "y": 775, "width": 820, "height": 100, "fontSize": 88, "fontWeight": 700, "fill": "#ffffff", "whiteSpace": "normal"}}
  ]}}}
```

- The whole document is checked before anything changes; every problem comes back with its object, its path, a refusal code and a corrected example. Nothing is applied if any is found (verified: scene-refusal-lists-every-problem).
- `dry_run: true` returns the change list and changes nothing. Send it again without `dry_run` for one undo step.
- An object keeps its scene `id`. Apply the same document again and only differences change (an exact no-op lists nothing); `scene.get` returns the same document, so `get -> apply -> get` is exact. `mode: "replace"` removes only objects that carry a scene id the new document leaves out.
- Types: `rect`, `ellipse`, `polygon`, `star`, `text`, `path` (SVG path data `d` in px on the node, beside `style`; `scene.get` hands `d` back; verified: path-node-in-a-scene), `group` (a transparent container its `children` ride), `background`, `solid`, `adjustment`, `null` (a transform only: a parent that draws nothing; see [../drawing/rigging.md](../drawing/rigging.md#null-object); verified: null-rig-pivot). A node's children are measured from its top-left.
- Keyframes of a node animate every design number: x, y, width, height, rotate, scale, opacity, transformOrigin, fill, stroke, the text sizes, and `softEdge`, `blur`, `glow`, `dropShadow`, `borderRadius`, `strokeWidth` and the trims (verified: scene-keyframes-take-the-effect-keys).
- The change list is `changes: [{object, key, before, after, unit}]` (keys are design names; `$created`, `$name`, `$parent`... mark structure).

## Selectors (verified: selectors-and-bulk-set)

Wherever a command takes `id` or `ids`, and with `select.query {selector}`: `#title` (scene id), `text`, `rect`, `Lower third` (name), `[tag=cta]`, `.cta`, `[name^="Lower"]`, `group text`, `group > text`, `:selected`, `:first-child`, `:nth-child(2)`, `a, b`. A per-object command aimed at several matches runs once for each in one undo step, all or nothing (`matched` lists them). A single-target command (`clip.rename`, `object.path`) refuses with `ambiguous` and names the candidates. `select.match {selector}` selects what it finds.

## Set, read, animate

```json
{"command": "property.set", "args": {"id": "#plate", "key": "borderRadius", "value": "50%"}}
{"command": "property.set", "args": {"id": "rect", "key": "opacity", "value": 0.5}}
{"command": "anim.set", "args": {"id": "#plate", "keyframes": [
  {"at": 0, "x": -900, "opacity": 0, "ease": "ease-out"}, {"at": "0.5s", "x": 160, "opacity": 1}]}}
{"command": "anim.set", "args": {"id": "#name", "from": {"opacity": 0, "y": "+=24px"}, "duration": "0.4s", "ease": "ease-out",
  "stagger": {"target": "words", "each": "80ms", "from": "start"}}}
{"command": "anim.set", "args": {"id": "#plate", "motionPath": {"d": "M 100 100 C 400 100 600 500 900 500", "duration": "1s", "ease": "ease-in-out"}}}
```

Verified: property-set-units-and-refusals, anim-keyframes-tweens-and-eases, text-stagger-gsap-style, motion-presets.

- `anim.set` writes plain keys in one undo step: `keyframes`, or the tweens `to` / `from` / `fromTo` (`duration` 0.5s, `delay` 0, `ease` `ease-out` by default; `"+=24px"` is relative to the value at the start). A keyframe with no `ease` is `linear`.
- A key's `ease` is the segment **leaving** it; the last key's ease is not stored and the reply says so. Steps and springs are baked into marked keys (the reply says how many); an easing name the build does not know is refused (`bad-ease`).
- A stagger (`target: chars | words | lines`, `each` or `amount`, `from: start | end | center | edges | random`, `ease`) is GSAP-style and plays the tween on every part. `each` rounds to whole frames (80 ms at 30 fps is 2 frames; the reply lists it).
- Presets as plain keys: `motion.list`, `motion.expand`, `motion.apply {id, preset, params}` for `fade-in`, `fade-up`, `slide-in`, `pop`, `wipe`, `typewriter`.
- `key.set {id, key, value, at, ease}` takes the same units and writes one key. `anim.get` and `key.list` read keys back in design units with the CSS ease leaving each key. `key.remove {id, key, at}` removes a key by design name at a frame (`at` or `atComp`; the playhead when omitted); `x` and `y` are one linked position track, so removing either takes the pair's key; a frame with no key is refused with where the key is (verified: keyed-soft-edge-feather-blur-trim). The stored path (`transform.placement.position`) still works.

## Effects, soft edges and masks in CSS terms (verified: effects-in-css-terms)

```json
{"command": "property.set", "args": {"id": "#name", "key": "blur", "value": "8px"}}
{"command": "property.set", "args": {"id": "#name", "key": "dropShadow", "value": "0 8px 12px #0008"}}
{"command": "property.set", "args": {"id": "#name", "key": "glow", "value": "12px #ffcc00 0.6 0.2"}}
{"command": "property.set", "args": {"id": "#name", "key": "filter", "value": "blur(4px) brightness(1.2)"}}
{"command": "property.set", "args": {"id": "#name", "key": "blur", "value": "none"}}
```

`filter` replaces the effects of its kinds (listed functions are added or updated in order, unlisted ones of those kinds are removed). `saturate`, `hue-rotate`, `invert`, `grayscale`, `sepia` and `backdrop-filter` are refused with the reason (no node in either host). Blur and glow are limited to 115 x W/1920 px. Soft edges and feather: [../effects/soft-edge.md](../effects/soft-edge.md). Masks and blend modes: [../effects/compositing-and-masks.md](../effects/compositing-and-masks.md).

## Helpers and checks that need no render

| Need | Command |
|---|---|
| Align, distribute, stack, grid, fit to the frame, safe area | `layout.align {ids, mode: left\|right\|top\|bottom\|centerX\|centerY\|center, to: frame\|safe\|selection}`, `layout.distribute {ids, axis}`, `layout.stack {ids, axis, gap}`, `layout.grid {ids, cols, gap}`, `layout.fit`, `layout.safe {safe: title\|action\|social}`; px, on layout boxes; refuse an animated position |
| The largest `fontSize` that fits | `text.fit {id, box: {width, height}, min, max}`; `text.balance {id}` evens the lines |
| Real boxes in px | `measure.boxes`, `measure.overlaps {within: "frame"\|"safe"}`, `measure.distance {a, b}`, `measure.contrast {fg, bg}` (WCAG on the displayed colours) |
| Lint, timing, expectations | `carvercat_inspect {mode: lint\|timing\|expect\|probe\|curves\|qc}` |
| What carves where | `carve.preflight {host: "resolve"\|"aftereffects"}`: per object and key, `exact`, `approximate` or `unsupported`; nothing is sent |

Verified: layout-and-measure-helpers, inspect-look-render. Run `carve.preflight` before every send and fix or accept each `approximate` and `unsupported` line.

## Headless notes

`carvercat-host --mcp` is a private document. With fresh `CARVERCAT_PREFS_DIR`, `CARVERCAT_DATA_DIR` and `CARVERCAT_CACHE_DIR`. The parameter registry is compiled in, and every command waits for fonts once, so a host started anywhere takes `softEdge` and text with no font call first. The bundled font families (Open Sans) are found only through `CARVERCAT_RESOURCE_ROOT` (the folder that holds the bundled fonts); without it `fontFamily: "Open Sans"` is refused as not installed ([KI-167](../known-issues.md#ki-167)). Python: `ai/scripts/cc_client.py` (`Client.stdio(exe, state_dir, resource_root=...)` does both), `cc_scene.py`; the app's own helper is `tools/carvercat_py/`.

## Old names, accepted for one release

The old keys still work for one release after the one that deprecates them and are marked old in every reply. They keep their traps; write the design names. `api.info` states the rule.

| Old | Trap | Use |
|---|---|---|
| `center`, `centerX`, `centerY`, `transform.placement.position` | normalised, y up, the **centre** | `x`, `y` px, top-left, y down |
| `angle`, `transform.placement.rotation` | counter-clockwise | `rotate` clockwise |
| `size`, `blend`, `anchor` | scale factor; opacity; half-size units y up | `scale`, `opacity`, `transformOrigin` |
| `shape.geometry.*.width`, `.height`, `cornerRadius`, stroke `width` | fractions of the frame **width** (both axes) | px |
| `text.font.size`, `textSize`, `tracking` | not a pixel height; face dependent | `fontSize` px, `letterSpacing` px |
| `blur.size`, `glow.size` (Fusion size units) | about 1.15 px of sigma per unit at 1920 | `blur "12px"`, `glow "12px ..."` |
| colour arrays | linear light | CSS strings |
| `Ease in`, `Ease out`, `S-curve` | arrive at a key; not CSS `ease-in`/`ease-out`. `Ease in` is `cubic-bezier(0.333, 0, 0.667, 0.333)`, `Ease out` is `cubic-bezier(0.333, 0.667, 0.667, 1)`, `S-curve` is `cubic-bezier(0.333, 0, 0.667, 1)` | `ease` on the key that leaves |
| `mask.make`, `shape.fill.softEdge` (fraction of width) | | `mask`, `clipPath`, `feather`, `softEdge` px |
