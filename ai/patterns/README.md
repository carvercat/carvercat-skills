# Motion pattern library

Tested building blocks for motion graphics.

Units. The templates and presets are stored in the project format; what you write when you edit or build around them is in design units: [design-units.md](../references/app/design-units.md). Run `carve.preflight` before a send.

Each one is either:

- **a preset**: a `.carverpreset` that animates ONE object relative to where it already is. Apply it with `preset.apply {name, id}` or drag it from the Library's Animation tab.
- **a template**: a `.carvertemplate` holding several coordinated objects. Use `library.place {name, frame}`, then `template.apply {id}` (check with `carve.preflight` before a send).
- **a recipe**: MCP steps, written out here, for patterns whose geometry depends on your content.

The pack lives in `library/templates/motion-patterns/` in this repo. Install it as in [Installing a pack](#installing-a-pack). It is regenerated by `ai/scripts/motion/build_pattern_pack.py` (presets and preview cards) and `ai/scripts/motion/comp_to_template.py` (templates, extracted from a built and checked comp in `categories/motion-patterns/pattern-lab/project.carverproj`).

## Installing a pack

Needs Carvercat 0.1.8 or later (not in the public 0.1.7).

1. In Carvercat choose Help > Library Folder, or have the agent run `library.folder` (`open: true` shows it). It creates the folder and returns its path.
2. Copy the pack folder (for example `motion-patterns/`) into its `templates/` subfolder. Scene templates go into `scene_templates/`.
3. Run `library.reload`, or wait a couple of seconds. Read `user.issues` in the reply: it lists clashes (a bundled item with the same name wins, and the user copy is skipped) and unreadable files.

Folders: public Mac `~/Library/Application Support/Carvercat/data/library`; public Windows `%APPDATA%\Carvercat\data\library`. Dev builds use their own folder; `library.folder` returns it.

Pack item names must not equal bundled item names.

Before 0.1.8, copying into a checkout's `library/templates/` works for checkout builds only.

Fonts: Carvercat uses its bundled fonts (Open Sans, Inter, Bricolage, JetBrains Mono) when they are not installed (E42). Resolve and After Effects still need any font installed on their machine. Rethink Sans is not bundled: install it first ([KI-136](../references/known-issues.md#ki-136)).

## What a template becomes (read before placing one)
`library.place {name, frame}` + `template.apply {id}` creates a **new nested comp** (named after the template) and places an **instance** of it in your comp. To recolour or retime its contents: `carvercat_list` (find the comp's index) → `comp.switch {index}` → edit → `comp.switch` back. Ids inside carry the template's prefix (`ttw_`, `iris_`, `lt_`, `logo_`, `bars_`). Animate the INSTANCE like any object (presets, position keys) for entrances and exits of the whole thing. Templates are fixed-length; for a longer hold, lengthen the nested comp (`comp.duration`) and drag its last clips' ends, or build from the recipe instead.

| Template | Inside | Has exit? | Length | Stand-ins to replace |
|---|---|---|---|---|
| Two-tone wipe | Scene A, Scene B (full-frame bgs), Wipe 1, Wipe 2 | n/a | 48 f | delete Scene A/B inside and put the instance on the top track over your cut, or build by hand (it is 2 rects) |
| Colour iris | Scene A, Scene B, Iris disc | n/a | 48 f | same as above |
| Lower third - accent bar | bar, name, role | yes | 120 f | text, colours |
| Logo - stamp reveal | mark (circle), wordmark, underline | no (hold) | 90 f | the mark; add your own exit on the instance |
| Bar chart - grow | baseline, 4 bars | no | 120 f | bar heights/colours; add labels and an exit |

## How to pick

1. Decide the role first: **hero** (one per scene, can be expressive), **support** (calm, expo/decel), **exit** (fast, accelerating, ~70% of the entrance length). See `../references/craft/motion-principles.md`.
2. Text with more than one word → a staggered text preset. A single object → an object preset. Several objects that must move as one idea → a template or recipe.
3. Never give two neighbours the same entrance at the same frame: offset them 3–6 frames (stagger) or contrast them (rise vs pop).
4. Every entrance needs an exit, and every hold longer than about 2 s needs some motion in the middle (drift, a slow 2–3% scale, parallax).

## Pitfalls (found while building these, all on 0.0.72)

1. **A text takes one staggered preset per property.** If the entrance staggers the position, a staggered exit on the position is refused ("already in a slot of the Stagger"). Give that text a non-staggered exit such as Exit up - accelerate; it moves the whole block.
2. **`preset.apply`, `comp.new` and `key.box` cannot go inside a batch.** Run them one by one with `carvercat_run`. Build the objects and set their properties around them with `scene.apply` and `property.set`.
3. **Stored preset easings are a fixed set** (linear, accelerating arrival `cubic-bezier(0.333, 0, 0.667, 0.333)` (stored as Ease out), decelerating arrival `cubic-bezier(0.333, 0.667, 0.667, 1)`, S curve `cubic-bezier(0.333, 0, 0.667, 1)`, hold). Any other name silently becomes linear in a stored preset. That is why this pack bakes its curves into keys with linear joins. In your own keys write any CSS easing on the key that leaves.
4. **Preset offsets are restated here with y DOWN.** The tables give `y +4.5% H` for a start below the rest position (the stored preset keeps a frame fraction with y up). Write your own positions in px from the top-left, y down.
5. **The pivot is `transformOrigin`**: `"0% 50%"` = left edge, `"50% 100%"` = bottom edge (stored anchors `[-1,0]` and `[0,-1]`). Setting it keeps the picture still (0.0.72 compensates the position), so set the pivot BEFORE seating the object with `layout.*`.
6. **`layout.*` and `measure.*` work at the playhead.** For an object that starts later, move the playhead inside the clip first, or it refuses with "no measurable geometry".
7. **There is no "remove all keys of a property".** Undo, or delete and rebuild the object, if a preset was wrong. Apply presets last.
8. **Two-layer wipes: the TOP layer must leave first** so that the lower colour trails behind it on the exit. In the same order both colours collapse into one.
9. **New comps restart clip ids at clip_1.** Ids repeat across comps; give templates unique ids (`comp_to_template.py --prefix`). See `../references/app/performance.md`.
