# Motion pattern library

Tested building blocks for motion graphics. Each one is either:

- **a preset**: a `.carverpreset` that animates ONE object relative to where it already is. Apply it with `preset.apply {name, id}` or drag it from the Library's Animation tab.
- **a template**: a `.carvertemplate` holding several coordinated objects. Use `library.place {name, frame}`, then `template.apply {id}`.
- **a recipe**: MCP steps, written out here, for patterns whose geometry depends on your content.

The pack lives in `library/templates/motion-patterns/` in this repo. Install it by copying that folder into Carvercat's `library/templates/` folder; the app picks it up within about 2 s, or run `library.reload`. It is regenerated by `ai/scripts/motion/build_pattern_pack.py` (presets and preview cards) and `ai/scripts/motion/comp_to_template.py` (templates, extracted from a built and checked comp in `categories/motion-patterns/pattern-lab/project.carverproj`).

**Status.** Everything marked "verified 0.0.72" was built in Carvercat 0.0.72 (rev 1071) and checked three ways:
- `carvercat_inspect mode:curves` for the measured overshoot and settle frame
- `carvercat_look` for the picture
- for templates, a placement into a fresh comp

Agent-neutral: nothing here depends on a particular AI. Any agent with the Carvercat MCP, or a human in the app, can follow it.

## What a template becomes (read before placing one)
`library.place {name, frame}` + `template.apply {id}` creates a **new nested comp** (named after the template) and places an **instance** of it in your comp. To recolour or retime its contents: `carvercat_list` (find the comp's index) → `comp.switch {index}` → edit → `comp.switch` back. Ids inside carry the template's prefix (`ttw_`, `iris_`, `lt_`, `logo_`, `bars_`). Animate the INSTANCE like any object (presets, position keys) for entrances and exits of the whole thing. Templates are fixed-length; for a longer hold, lengthen the nested comp (`comp.duration`) and drag its last clips' ends, or build from the recipe instead.

## How to pick

1. Decide the role first: **hero** (one per scene, can be expressive), **support** (calm, expo/decel), **exit** (fast, accelerating, ~70% of the entrance length). See `../references/craft/motion-principles.md`.
2. Text with more than one word → a staggered text preset. A single object → an object preset. Several objects that must move as one idea → a template or recipe.
3. Never give two neighbours the same entrance at the same frame: offset them 3–6 frames (stagger) or contrast them (rise vs pop).
4. Every entrance needs an exit, and every hold longer than about 2 s needs some motion in the middle (drift, a slow 2–3% scale, parallax).

## Pitfalls (found while building these, all on 0.0.72)

1. **A text takes one staggered preset per property.** If the entrance staggers `center`, a staggered exit on `center` is refused ("already in a slot of the Stagger"). Give that text a non-staggered exit such as Exit up - accelerate; it moves the whole block.
2. **`preset.apply`, `comp.new` and `key.box` cannot go inside `carvercat_batch`.** Run them one by one with `carvercat_run`. Batch the object creation and property sets around them.
3. **Preset easings are names only** (Linear, Ease in, Ease out, S-curve, Hold). Any other name, such as "Ease in and out" or "easeOutBack", silently becomes Linear. That is why this pack bakes its curves into keys with linear joins.
4. **Y is up.** Position offsets in presets and `center` values are frame fractions with y up: `[0,-0.04]` is BELOW the rest position.
5. **The anchor is in half-sizes of the object**: `[-1,0]` = left edge, `[0,-1]` = bottom edge. Setting it keeps the picture still (0.0.72 compensates the position), so set the anchor BEFORE seating the object with `authoring.place_bounds`.
6. **`authoring.place_bounds` measures at the playhead.** For an object that starts later, give the batch step a `frame` inside the clip, or it refuses with "no measurable geometry".
7. **There is no "remove all keys of a property".** Undo, or delete and rebuild the object, if a preset was wrong. Apply presets last.
8. **Two-layer wipes: the TOP layer must leave first** so that the lower colour trails behind it on the exit. In the same order both colours collapse into one.
9. **New comps restart clip ids at clip_1.** Ids repeat across comps; give templates unique ids (`comp_to_template.py --prefix`). See `../references/app/performance.md`.
